==========================================================
   ECOSORT DEPLOYMENT SUMMARY & GUIDE
==========================================================
Dibuat pada: 14 Mei 2026
Project ID: wasteclassifier-496217
Teknologi: React, Node.js, Docker, Google Cloud Run

----------------------------------------------------------
1. PERSIAPAN DOCKER (Buku Resep)
----------------------------------------------------------
- Dockerfile: Instruksi untuk Google Cloud cara membangun 
  aplikasi (Frontend Build -> Backend Run).
- .dockerignore: Daftar file yang dilarang masuk ke cloud 
  (node_modules, .env, .git) agar upload ringan dan cepat.

----------------------------------------------------------
2. PERSIAPAN GOOGLE CLOUD CLI
----------------------------------------------------------
- Pindah ke folder project di terminal:
  cd "D:\! Data Perkuliahan (PENTING)\VIBECODINGComp"

- Login ke akun Google:
  gcloud auth login

- Set project aktif:
  gcloud config set project wasteclassifier-496217

----------------------------------------------------------
3. PROSES BUILD (Memasak Container)
----------------------------------------------------------
Perintah untuk mengirim kode dan membuat Container Image:
gcloud builds submit --tag gcr.io/wasteclassifier-496217/ecosort-app

Konsep:
- Tag (gcr.io/...): Label alamat agar image tersimpan di 
  gudang (Registry) milik project kamu.

----------------------------------------------------------
4. PROSES DEPLOY (Menyalakan Website)
----------------------------------------------------------
Perintah untuk menjalankan container menjadi URL publik:
gcloud run deploy ecosort-app --image gcr.io/wasteclassifier-496217/ecosort-app --platform managed --region asia-southeast2 --allow-unauthenticated --set-env-vars "GEMINI_API_KEY=KUNCI_API_KAMU"

Konsep:
- --allow-unauthenticated: Website bisa dibuka siapa saja.
- --set-env-vars: Memasukkan API Key secara aman ke server.

----------------------------------------------------------
5. CARA REVISI & UPDATE
----------------------------------------------------------
Jika ada perubahan kode:
1. Edit kode di VS Code.
2. Tes di localhost:5173.
3. Jalankan lagi perintah BUILD (Langkah 3).
4. Jalankan lagi perintah DEPLOY (Langkah 4) atau klik 
   "Edit & Deploy New Revision" di Dashboard Cloud Run.

----------------------------------------------------------
6. TIPS PENTING
----------------------------------------------------------
- Revision History: Kamu bisa rollback ke versi lama jika 
  versi baru ada bug.
- IAM Permissions: Pastikan akunmu punya role "Cloud Build 
  Editor" agar bisa melakukan build.
- Incognito Mode: Gunakan ini untuk mengetes default theme 
  (Light/Dark) agar tidak terganggu cache browser.
