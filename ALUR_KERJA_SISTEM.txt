==========================================================
       ALUR KERJA SISTEM: TRASH CLASSIFIER ENGINE V3.5
==========================================================

1. TAHAP FRONTEND (Capture & Optimization)
------------------------------------------
- Kamera menangkap gambar menggunakan library react-webcam.
- Dukungan File Upload untuk gambar dari galeri lokal.
- Gambar dikompresi untuk mempercepat transmisi data ke server.

2. TAHAP BACKEND (API Handling & Strict Mode)
---------------------------------------------
- Node.js (Express) menerima request Base64.
- Implementasi "STRICT MODE": AI dilatih untuk mengenali objek non-sampah.
- Jika objek bukan sampah (wajah, hewan, gadget utuh), sistem akan memberikan kategori khusus.

3. TAHAP INTELLIGENCE (Gemini 3 Flash Engine)
---------------------------------------------
- AI berperan sebagai "EcoSort Intelligence" (Pakar Lingkungan Indonesia).
- Menggunakan JSON Schema Terstruktur untuk akurasi data 100%.
- Analisis mencakup:
  * Klasifikasi (Organik, Anorganik, B3, Bukan Sampah).
  * Detail Material (Plastik PET, HDPE, Logam, dll).
  * Penanganan Spesifik (Langkah cuci bersih, pisahkan tutup).
  * Penentuan Warna Tong Standar Indonesia (Hijau, Kuning, Merah, Abu-abu).

4. TAHAP DATA CLEANING (Extraction)
-----------------------------------
- Backend memproses respon murni JSON dari Gemini SDK.
- Error Handling otomatis untuk menangani API Quota Limit (429) dengan retry mechanism.

5. TAHAP GEO-INTELLIGENCE (Bank Sampah Locator)
-----------------------------------------------
- Frontend menggunakan Browser Geolocation API untuk mendeteksi posisi user.
- Menghubungi "Satelit" OpenStreetMap melalui Overpass API (Multi-Server Fallback).
- Mencari lokasi TPS3R, Bank Sampah, dan Recycle Center dalam radius 20km.
- Navigasi langsung ke Google Maps untuk pembuangan sampah yang bertanggung jawab.

6. TAHAP DISPLAY & PERSISTENCE (User Interface)
-----------------------------------------------
- React merender kartu hasil analisis dengan animasi Framer Motion.
- Data tersimpan secara lokal (Local Storage) untuk tracking dampak lingkungan.
- Statistik CO2 Saved dan Eco-Points dihitung secara otomatis berdasarkan riwayat scan.
