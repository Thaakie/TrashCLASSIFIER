==========================================================================
                 LAPORAN TEKNIS SISTEM: ECOSORT V3
          AI-POWERED WASTE CLASSIFICATION SYSTEM (INDONESIA)
==========================================================================

1. DESKRIPSI PROYEK
-------------------
EcoSort V3 adalah aplikasi berbasis web yang dirancang untuk membantu 
masyarakat Indonesia dalam mengklasifikasikan sampah secara otomatis 
menggunakan teknologi Computer Vision dan Kecerdasan Buatan (AI). 
Sistem ini menggunakan arsitektur modular untuk performa dan skalabilitas tinggi.

2. TEKNOLOGI YANG DIGUNAKAN (TECH STACK)
----------------------------------------
- Frontend: React.js (Vite), Tailwind CSS, Framer Motion, React Router (Navigation).
- Backend: Node.js, Express.js (Modular Router & Controller).
- AI Engine: Google Gemini 3.1 Flash Lite (High Efficiency).
- AI SDK: Official Google Generative AI SDK (@google/generative-ai).
- Icons: Lucide React.
- UI Components: Shadcn UI (Radix UI).

3. ARSITEKTUR SISTEM (MODULAR DESIGN)
-------------------------------------
Sistem telah direfaktorisasi menjadi struktur modular:

A. Frontend Architecture:
   - src/pages/: Komponen halaman terpisah (Home, Scanner, Impact, Education).
   - src/layouts/: Komponen navigasi global (Navbar, Footer).
   - src/hooks/: Custom hooks untuk logika (useTrashScanner).
   - React Router: Implementasi navigasi berbasis URL (SPA).

B. Backend Architecture:
   - src/routes/: Pemisahan endpoint API (/api/classify).
   - src/controllers/: Logika bisnis dan pemrosesan gambar terisolasi.
   - src/config/: Konfigurasi pusat untuk AI Engine dan JSON Schema.

4. FITUR UTAMA & PENINGKATAN
----------------------------
a. Smart Scanning: Deteksi real-time dengan kamera atau galeri foto.
b. Side-by-Side Dashboard: Visualisasi statistik dampak lingkungan (CO2 Saved, Points).
c. Daily Eco-Tips: Pesan edukasi harian dinamis untuk meningkatkan engagement.
d. Retry Mechanism: Logika percobaan ulang otomatis jika terjadi limit kuota API.
e. Gallery Upload: Dukungan pemrosesan file gambar dari penyimpanan lokal.
f. Dark Mode Support: Interface adaptif untuk kenyamanan visual.

5. ALUR KERJA TEKNIS (WORKFLOW V3)
----------------------------------
1. Input: User mengambil foto via webcam atau mengunggah dari galeri.
2. Processing: Data dikonversi ke Base64 dan dikirim ke backend modular.
3. AI Analysis: Backend menggunakan SDK resmi Gemini untuk analisis gambar 
   dengan instruksi sistem ahli lingkungan Indonesia.
4. Response Format: Output dijamin dalam format JSON terstruktur untuk 
   menghindari error parsing.
5. Storage: Hasil scan otomatis tersimpan di Local Storage dan diumpankan 
   ke dashboard Impact.

6. STATUS PENANGANAN QUOTA
--------------------------
Untuk mengatasi limitasi kuota API (Error 429), sistem saat ini menggunakan:
- Model: Gemini 3.1 Flash Lite (Kuota RPD lebih besar: 500/hari).
- Logic: Automatic exponential backoff (Retry per 10 detik).
