==========================================================================
                 LAPORAN TEKNIS SISTEM: ECOSORT V3.5
          AI-POWERED WASTE CLASSIFICATION SYSTEM (INDONESIA)
==========================================================================

1. DESKRIPSI PROYEK
-------------------
EcoSort V3.5 adalah aplikasi berbasis web yang dirancang untuk membantu 
masyarakat Indonesia dalam mengklasifikasikan sampah secara otomatis 
menggunakan teknologi Computer Vision dan Kecerdasan Buatan (AI). 
Sistem ini menggunakan arsitektur modular untuk performa dan skalabilitas tinggi.

2. TEKNOLOGI YANG DIGUNAKAN (TECH STACK)
----------------------------------------
- Frontend: React.js (Vite), Tailwind CSS v4, Framer Motion, React Router.
- Backend: Node.js, Express.js (Modular Router & Controller).
- AI Engine: Google Gemini 3.1 Flash Lite (High Efficiency).
- Geo-Locator: OpenStreetMap (Overpass API) with Multi-Server Fallback.
- AI SDK: Official Google Generative AI SDK (@google/generative-ai).
- Icons: Lucide React.
- UI Components: Shadcn UI (Radix UI).

3. ARSITEKTUR SISTEM (MODULAR DESIGN)
-------------------------------------
Sistem telah direfaktorisasi menjadi struktur modular:

A. Frontend Architecture:
   - src/pages/: Halaman terpisah (Home, Education, Locations, Impact).
   - src/hooks/: Custom hooks untuk logika kamera & AI (useTrashScanner).
   - Dynamic Routes: Penanganan navigasi antar fitur secara halus.

B. Backend Architecture:
   - src/config/: Konfigurasi pusat untuk prompt AI dan JSON Schema.
   - src/controllers/: Logika bisnis terisolasi untuk klasifikasi gambar.
   - Error Handler: Penanganan global untuk API limit (429) & server timeouts.

4. FITUR UTAMA & PENINGKATAN
----------------------------
a. Smart Scanning: Deteksi real-time dengan kamera atau galeri foto.
b. AI Strict Intelligence: Mampu membedakan sampah vs non-sampah (wajah, hewan, dll).
c. Real-time Bank Sampah Locator: Integrasi OpenStreetMap (OSM) untuk mencari 
   lokasi pembuangan terdekat di seluruh Indonesia secara dinamis.
d. Multi-Server Fallback: Sistem cadangan otomatis jika server API satelit sibuk.
e. Impact Tracking: Visualisasi statistik dampak lingkungan (CO2 Saved, Points).
f. Voice-over Guidance: Fitur suara untuk memberikan tips edukatif secara otomatis.
g. Dark/Light Mode: Interface premium dengan dukungan tema adaptif.

5. ALUR KERJA TEKNIS (WORKFLOW V3.5)
------------------------------------
1. Input & Localization: User memberikan input gambar; sistem mendeteksi lokasi geografis.
2. Analysis: Backend Gemini 3.1 Flash memproses gambar dengan standar lingkungan Indonesia.
3. Logic handling: Sistem membedakan kategori (Organik/Anorganik/B3) atau menolak (Bukan Sampah).
4. Discovery: Jika sampah anorganik terdeteksi, user dapat langsung mencari 
   Bank Sampah terdekat via satelit OSM.
5. Persistence: Data histori tersimpan di Local Storage untuk akumulasi poin.

6. STATUS PENANGANAN SISTEM
--------------------------
- Gemini API: Stabil dengan model Flash Lite (Retry 10s enabled).
- Geolocation: Aktif (Mendukung radius pencarian 20km).
- Data Source: OpenStreetMap (Overpass API) dengan fallback mechanism.
